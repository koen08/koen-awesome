# koen-awesome

Личная подборка полезных инструментов и утилит для работы с GitHub. Здесь нет цели собрать «всё подряд»: я добавляю только то, что зацепило, — чтобы попробовать сразу или вернуться, когда появится подходящая задача.

## Разделы

- **[Дизайн и UI](design.md)** — скиллы и инструменты, которые помогают проектировать, чинить и «расчеловечивать» интерфейсы.
- **[MCP-серверы](mcp.md)** — серверы и навыки, через которые агент читает данные из внешних сервисов.
- **[Текст](text.md)** — инструменты, которые убирают из текста признаки машинного письма.
