# AGENTS.md

Этот репозиторий — личная подборка полезных инструментов. `README.md` — оглавление,
остальные файлы в корне — тематические списки.

## Структура

- `README.md` — вступление и разделы: название, ссылка, одно предложение о чём раздел. Записей инструментов здесь нет.
- `<тема>.md` — один файл на тему (`design.md`, `text.md`, ...). Внутри заголовок на русском и список записей.
- Имя файла — короткий латинский слаг в нижнем регистре: `cli.md`, `actions.md`.
- Новый файл появляется только вместе с первой записью, пустых разделов не создавать.

## Формат записи

- **[Название](https://github.com/owner/repo)** — одно предложение: какую задачу решает.

Правила:

- описание — про задачу, а не про набор фич, максимум ~120 символов;
- название — как в репозитории или проекте;
- ссылка рабочая, желательно на GitHub;
- одна запись — одна строка, без вложенных списков;
- внутри файла — по алфавиту;
- без статусов, эмодзи, бейджей и скриншотов, пока не попросили явно;
- язык описаний — русский.

## Как добавить инструмент

1. Найти тему. Если файл есть — добавить строку в алфавитном порядке.
2. Если темы нет — создать `<слаг>.md` с заголовком и первой записью.
3. Добавить или обновить раздел в `README.md`: название, ссылка, описание.
4. Проверить ссылку: `gh api repos/<owner>/<repo> --jq '.full_name'`.

## Чего не делать

- не превращать `README.md` в список инструментов;
- не добавлять записи без короткого описания;
- не переписывать существующие формулировки без причины;
- не переименовывать файлы без обновления ссылок в `README.md`.
